\begin{abstract}
This report studies market making as a finite-horizon control problem using Markov Decision Processes (MDPs), Dynamic Programming (DP), and Reinforcement Learning (RL). The methodology is organized as a comparison ladder: first solve a small discretized model exactly with DP, then train RL on the same task with a discrete state representation, and finally relax the representation to continuous state variables and, in the last experiment, continuous actions. Experiments 1--3 therefore compare exact planning against progressively more flexible learned policies, while Experiment 4 moves to a continuous state-action setting trained with Soft Actor--Critic (SAC). The central theme is that DP is the exact benchmark inside the discretized model, whereas RL becomes increasingly attractive as discretization becomes restrictive and continuous control becomes the more natural formulation.
\end{abstract}

% ─────────────────────────────────────────────────────────────────────────────
\section{Introduction}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Motivation and Problem Setting}

A market maker repeatedly posts bid and ask quotes, earns spread revenue when orders arrive, and absorbs inventory risk after every fill. The core tradeoff is simple but dynamic: tighter quotes increase execution probability and spread capture, while accumulated inventory makes future price moves more dangerous. This makes market making a natural finite-horizon MDP.

The methodological challenge is that the same control problem admits very different solution methods depending on how richly it is modeled. If the state, action, and transition law are all small and known, DP gives an exact solution. Once price, volatility, and eventually continuous quote placement and sizing are introduced, exact tabulation becomes less natural and RL becomes the practical alternative. Our report is built around that transition.

\subsection{Project Structure}

The report follows the course progression from exact control to approximate control. Phase 1 formulates the market-making problem as an MDP and clarifies the simplified and realistic versions we study. Phase 2 solves the smallest discretized version exactly with DP. Phase 3 then enlarges the state description in stages and compares three levels of methodology whenever possible: DP on the discretized model, RL with the same discrete state representation, and RL with continuous state inputs. Experiment 4 completes the progression by moving to continuous state-action control with SAC.

\section{Phase 1: Problem Definition and Markov Description}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Problem Specialization and Practical Relevance}

We study single-asset market making. At each step the agent chooses bid and ask quotes, and in the most realistic version also chooses quote sizes. The objective is not just to maximize spread capture, but to do so while controlling inventory and limiting exposure to adverse price moves. This is a good fit for the course because it has an interpretable small-model DP baseline and a natural extension to higher-dimensional and continuous RL settings.

\subsection{Three Versions of the Problem}

Following the project guidance, we work with three nested versions of the same market-making problem.

\begin{itemize}
    \item \textbf{Ideal full problem.} A rich market state, continuous quote placement and quote sizing, and possibly extra latent signals such as order-flow imbalance or regime variables.
    \item \textbf{Phase 3 course version.} A realistic but still simulator-friendly version with inventory, price deviation, and stochastic volatility, culminating in continuous state-action control with SAC.
    \item \textbf{Phase 2 simplified version.} An inventory-only discrete model with constant volatility and a small action grid, chosen precisely because it is small enough to solve exactly with DP.
\end{itemize}

These are not separate problems. They are progressively richer parameterizations of the same control task, which lets us carry the intuition of the small exact model into the larger RL settings.

\subsection{MDP Formulation}

\subsubsection{State}

The state always includes the current inventory $I_t$. In richer versions we add the mid-price deviation and stochastic volatility:
\begin{equation}
    s_t =
    \begin{cases}
        I_t, & \text{Phase 2 / Experiment 1}, \\
        (I_t, S_t), & \text{Experiment 2}, \\
        (I_t, S_t, \sigma_t), & \text{Experiment 3}, \\
        (I_t, \tilde S_t, \tilde \sigma_t), & \text{Experiment 4}.
    \end{cases}
\end{equation}
In the DP baseline and in the discrete-RL baselines, these variables are placed on finite grids. In the continuous-RL baselines and the SAC experiment, the same economic variables are fed in as continuous features.

\subsubsection{Action}

In Experiments 1--3 the action is a discrete pair of asymmetric bid and ask half-spreads:
\begin{equation}
    a_t = (\delta_t^{\mathrm{bid}}, \delta_t^{\mathrm{ask}}).
\end{equation}
The action grid is intentionally small enough for DP but still rich enough to allow meaningful inventory skew.

In Experiment 4 the action becomes continuous and additionally includes quote sizes:
\begin{equation}
    a_t = (\delta_t^{\mathrm{bid}}, \delta_t^{\mathrm{ask}}, q_t^{\mathrm{bid}}, q_t^{\mathrm{ask}}),
\end{equation}
where both spread placement and order size are chosen continuously.

\subsubsection{Transition Dynamics}

The market maker posts bid and ask quotes around the mid-price $S_t$:
\begin{equation}
    \text{bid} = S_t - \delta_t^{\mathrm{bid}}, \qquad
    \text{ask} = S_t + \delta_t^{\mathrm{ask}}.
\end{equation}

Customer orders arrive as independent Poisson processes with spread-dependent intensity
\begin{equation}
    \lambda(\delta) = A \exp(-k \delta),
\end{equation}
so the per-step fill probability on one side is
\begin{equation}
    P(\text{fill}\mid \delta) = 1 - \exp(-\lambda(\delta)).
\end{equation}
Tighter spreads therefore attract more flow but expose the agent to greater inventory risk.

The mid-price evolves according to adverse selection plus noise:
\begin{equation}
    \Delta S_t = \eta \left(\mathbf{1}_{\mathrm{ask\,fill}} - \mathbf{1}_{\mathrm{bid\,fill}}\right) + \sigma_t \varepsilon_t,
    \qquad \varepsilon_t \sim \mathcal{N}(0,1).
\end{equation}
An ask fill (someone buying from us) signals informed buying pressure and tends to push the price upward; a bid fill has the opposite effect.

In Experiment 3 and the continuous SAC experiment, volatility evolves stochastically via an Ornstein--Uhlenbeck-style process:
\begin{equation}
    \Delta \sigma_t = \kappa(\bar \sigma - \sigma_t) + \xi \varepsilon_t^v,
    \qquad \varepsilon_t^v \sim \mathcal{N}(0,1),
\end{equation}
with a lower floor to prevent degenerate volatility values.

\subsubsection{Reward and Constraints}

At each step, the reward combines realized spread capture, mark-to-market inventory P\&L, and a quadratic inventory penalty:
\begin{equation}
    r_t =
    \underbrace{\delta_t^{\mathrm{bid}} \mathbf{1}_{\mathrm{bid}} + \delta_t^{\mathrm{ask}} \mathbf{1}_{\mathrm{ask}}}_{\text{spread capture}}
    +
    \underbrace{I_t \Delta S_t}_{\text{inventory P\&L}}
    -
    \underbrace{\alpha I_t^2}_{\text{inventory penalty}}.
\end{equation}
At the terminal step, we apply an additional penalty proportional to the magnitude of remaining inventory to discourage carrying large positions to the end of an episode.

Inventory is bounded by $|I_t| \le I_{\max}$. Fills that would breach the inventory boundary are blocked, so the action space is effectively state-dependent near the edges.

\subsection{Modeling Choices Across Phases}

The Phase 2 simplification keeps only the core inventory-control tradeoff: inventory is the full state, volatility is constant, and the action space is a small discrete grid of bid/ask spreads. Phase 3 restores realism in stages: Experiment 2 adds price, Experiment 3 adds stochastic volatility, and Experiment 4 replaces the grid-based action description with continuous quote placement and sizing. Methodologically, this creates a clean ladder from exact DP to discrete RL to continuous RL.

\section{Phase 2: Dynamic Programming Solution}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Simplified Phase 2 Model and DP Method}

The canonical Phase 2 model is the inventory-only formulation used in Experiment 1. The state is
\begin{equation}
    s_t = I_t \in \{-I_{\max}, \ldots, I_{\max}\},
\end{equation}
and volatility is fixed at $\sigma_{\mathrm{base}}$. With $I_{\max}=5$, the state space contains only $11$ inventory levels, so the problem is small enough to solve exactly.

Because the experiments have a finite episode length and an explicit terminal inventory penalty, we solve the discretized model by finite-horizon backward induction:
\begin{equation}
    V_t(s) = \max_a \mathbb{E}\!\left[r_t(s,a,S_{t+1}) + \gamma V_{t+1}(S_{t+1}) \mid S_t=s, A_t=a \right],
\end{equation}
with terminal condition
\begin{equation}
    V_T(s) = -\lambda |I_T|.
\end{equation}
This makes the DP policy time-dependent near the episode end, which is exactly what we want in a market-making problem with terminal inventory control. Within this discretized MDP, DP is the exact benchmark.

\subsection{RL Baselines and the Comparison Ladder}

The Phase 2 baseline already exposes the key qualitative structure of the problem: high positive inventory should tilt the policy toward selling, and high negative inventory should tilt it toward buying. That inventory-skew logic is the main structural pattern we expect every learned policy to recover.

For Experiments 1--3, we compare methods using a consistent ladder:
\begin{enumerate}
    \item \textbf{DP}: exact planning on the discretized finite-horizon MDP.
    \item \textbf{RL (discrete)}: a DQN trained on the same discretized state representation as DP.
    \item \textbf{RL (continuous)}: a DQN trained on continuous state features when richer state variables are present.
\end{enumerate}

This design lets us separate two questions. First, how much performance is lost when we replace exact planning by a learned value-based policy on the same state grid? Second, what changes when we remove the state discretization and let RL consume the raw continuous covariates directly? In that sense, DP is the exact upper bound only for the discretized MDP itself; the continuous-state RL baseline is not solving exactly the same tabular problem, but it is the more flexible approximation that becomes attractive once discretization starts to bite.

\subsection{Experiment 1: Inventory-Only DP vs.\ RL}

Experiment 1 is the cleanest validation case. The state contains only inventory, so there is no meaningful distinction yet between a discretized market state and a continuous market state; both would reduce to the same one-dimensional signal. For that reason, Experiment 1 compares DP against the discrete DQN only and uses the result as the anchor for the later richer experiments.

\section{Phase 3: Reinforcement Learning in Richer Environments}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{RL Setup}

Experiments 2 and 3 use two DQN baselines with the same discrete action set but different state representations. The \textbf{discrete} DQN sees the same binned state that DP sees, so it is the closest learned approximation to the exact benchmark. The \textbf{continuous} DQN instead receives the underlying state variables as continuous features, avoiding state discretization while keeping the action space discrete. This is useful because it lets us compare discretized and continuous representations at every stage before moving all the way to continuous control.

Experiment 4 then replaces the DQN family with \textbf{Soft Actor--Critic (SAC)}. This is the appropriate shift once the action itself becomes continuous: value-based methods are natural when the action set is enumerable, whereas actor-critic methods are better suited to learning in a continuous action space without an explicit discrete maximization over actions.

\subsection{Experiment 2: Inventory and Price}

Experiment 2 extends the state to include both inventory and price deviation:
\begin{equation}
    s_t = (I_t, S_t) \in \{-I_{\max}, \ldots, I_{\max}\} \times \mathcal{G}_S.
\end{equation}
The price grid has $21$ bins over $[-10,10]$, so the DP model has $11 \times 21 = 231$ states. We then compare three policies on this problem: DP on the discretized grid, a DQN trained on the same binned state, and a DQN trained on the exact continuous price input. This makes Experiment 2 the first direct test of the discrete-versus-continuous RL representation question.

Inventory remains the dominant control signal, but the problem is now genuinely two-dimensional. DP is still the exact benchmark on the binned model. The discrete DQN tells us how much of that benchmark can be recovered by value-based RL on the same grid, while the continuous DQN tests whether replacing the price bin by the exact floating-point input yields a smoother or more flexible learned policy. The main methodological lesson is that once price enters the state, representation choice becomes part of the problem, not just the optimizer.

\subsection{Experiment 3: Inventory, Price, and Volatility}

Experiment 3 adds stochastic volatility to the state:
\begin{equation}
    s_t = (I_t, S_t, \sigma_t)
    \in \{-I_{\max}, \ldots, I_{\max}\} \times \mathcal{G}_S \times \mathcal{G}_{\sigma}.
\end{equation}
In the implementation, the price grid has $15$ bins and the volatility grid has $9$ bins, producing a total discretized state space of $11 \times 15 \times 9 = 1{,}485$ states. As in Experiment 2, we compare DP, a discrete-state DQN, and a continuous-state DQN. The difference is that the continuous baseline now receives both price and volatility as raw features rather than as bins.

Figures~\ref{fig:exp3} and~\ref{fig:exp3_heatmap} show the same methodology under a harder state process. Once volatility is part of the state, the reward becomes much noisier because inventory P\&L depends on the interaction of inventory, adverse selection, and stochastic volatility. The three-way comparison now becomes more informative: DP still supplies the exact benchmark on the discretized MDP, the discrete DQN tests whether RL can reproduce that benchmark on the same grid, and the continuous DQN tests whether feeding in raw price and volatility improves generalization enough to offset the harder learning problem. This is exactly the regime in which DP is still valuable as a benchmark, but continuous RL starts to look more like the eventual target methodology.

\subsection{Experiment 4: Continuous State-Action Control with SAC}

The final experiment removes the grid-based action simplification and moves to a continuous state-action formulation. The state is
\begin{equation}
    s_t = (I_t, \tilde S_t, \tilde \sigma_t) \in [-1,1] \times \mathbb{R} \times \mathbb{R}_+,
\end{equation}
where inventory is continuous in $[-1,1]$, price deviation is normalized by a fixed scale, and volatility is normalized by its long-run mean. The action includes both quote placement and quote size:
\begin{equation}
    a_t = (\delta_t^{\mathrm{bid}}, \delta_t^{\mathrm{ask}}, q_t^{\mathrm{bid}}, q_t^{\mathrm{ask}}),
\end{equation}
with continuous spread bounds $\delta \in [0.1, 3.0]$ and continuous quote-size bounds $q \in [0, 0.15]$. The environment keeps the same economic structure as the earlier experiments: spread-dependent Poisson fills, adverse selection, OU-style stochastic volatility, quadratic inventory penalty, and a terminal inventory penalty.

This is the closest setting to the full objective of the project. DP is no longer a natural comparator because both the state and action spaces are continuous, and a DQN is no longer the right tool because the action is not enumerable. We therefore train a Soft Actor--Critic policy with Stable-Baselines3 using an MLP policy, discount factor $\gamma=0.99$, learning rate $3\times 10^{-4}$, replay buffer of size $100{,}000$, batch size $128$, soft target update $\tau=0.005$, and automatic entropy tuning. The notebook uses a small-budget run of $20{,}000$ environment steps, with deterministic evaluation every $10{,}000$ steps and a final detailed evaluation over $500$ fresh episodes.

Over 500 evaluation episodes, the trained SAC policy achieved the following summary metrics:

The SAC results are positive but deliberately modest, which is exactly what we should expect from a short-budget continuous-control run. Mean reward and mean episode P\&L are both positive, so the learned policy is profitable on average. At the same time, the reward standard deviation is large relative to the mean, which keeps the Sharpe-like ratio low. Inventory is controlled reasonably well: the mean absolute inventory of $0.255$ and mean absolute final inventory of $0.292$ are comfortably inside the hard inventory bounds, showing that the policy has learned mean reversion rather than simply maximizing fills. The main interpretation is therefore not that SAC has fully solved the realistic problem, but that it already learns the correct qualitative market-making behavior in the fully continuous setting and does so without any state or action discretization.

\subsection{From DP to RL as Complexity Grows}

The progression from Experiments 1 through 4 makes the methodology explicit. DP is the right tool when the model is known and the discretized state-action space is small enough to enumerate. Discrete-state RL is the closest learned approximation to that benchmark. Continuous-state RL then relaxes the representation while keeping the same economic task, and SAC finally removes the discrete action grid entirely.

\begin{figure}[htbp]

Figure~\ref{fig:exp2_runtime} illustrates the computational tradeoff directly. DP is extremely attractive when the discretized model is still small enough to be solved within reasonable time. Experiment 3 already pushes that tradeoff harder, and Experiment 4 removes exhaustive tabulation altogether by moving to continuous state and action spaces.

\section{Discussion}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Main Lessons Across Experiments}

Several qualitative patterns are consistent across the experiments. First, inventory mean reversion is the dominant structural feature of the policy throughout the project. Second, once price is added to the state, the representation itself matters: discrete and continuous RL are no longer solving the same approximation problem. Third, once volatility is added, the reward becomes materially noisier and the gap between exact planning and approximate learning becomes more informative.

The project also shows that ``comparing against DP'' must be interpreted carefully. DP is an exact upper bound only for the same discretized MDP. The discrete DQN is therefore the closest learned comparator, while the continuous DQN and the SAC policy trade exact comparability for a representation that is closer to the eventual realistic control problem.

\subsection{Strengths and Limitations}

The main strength of the project is that the same market-making task is carried through a coherent methodological ladder. That makes the comparisons meaningful: we are not switching problems, only enlarging the state and action descriptions and relaxing the representation assumptions. The main limitation is equally clear: as the environment becomes more realistic, the reward signal gets noisier and the comparisons become less exact, especially once the continuous-control SAC experiment departs from the discrete-action setup.

% ─────────────────────────────────────────────────────────────────────────────
\section{Conclusion}
% ─────────────────────────────────────────────────────────────────────────────

This project implements a coherent progression from exact planning to continuous-control RL. We begin with a small finite-horizon market-making MDP that can be solved exactly with DP, use that as the benchmark for discrete RL, then relax the state representation to continuous inputs, and finally move to continuous actions with SAC. The main takeaway is not that one method dominates everywhere, but that each method is most appropriate at a different level of model complexity: DP for exact small models, discrete RL for approximate learning under the same action grid, and continuous RL once the richer formulation becomes the real object of interest.

\section{Appendix}
\subsection{DQN Agent Architecture}

\textbf{Network.}
For Experiments 1--3, both the online network $Q_\theta$ and the target network $Q_{\theta^-}$ are multilayer perceptrons with two hidden ReLU layers:
\[
  \mathrm{Linear}(d_s, h) \to \mathrm{ReLU} \to \mathrm{Linear}(h, h) \to \mathrm{ReLU} \to \mathrm{Linear}(h, |\mathcal{A}|)
\]
where $d_s$ is the state dimension, $|\mathcal{A}| = n^2$ is the number of joint bid/ask spread actions, and the hidden width $h$ is chosen per experiment (larger in the richer state settings).

\textbf{Double DQN.}
The online network selects the $\epsilon$-greedy next action; the target network evaluates it:
\[
  y_t = r_t + \gamma \cdot Q_{\theta^-}\!\left(s_{t+1},\; \arg\max_{a}\, Q_\theta(s_{t+1}, a)\right)
\]
This decouples action selection from value estimation, reducing overestimation bias.

\textbf{Loss and replay.}
Huber (Smooth $L_1$) loss is minimized over mini-batches drawn from an experience replay buffer of capacity $50\,000$:
\[
  \mathcal{L}(\theta) = \mathrm{SmoothL_1}\!\left(Q_\theta(s, a),\; y_t\right)
\]

\textbf{Optimiser and target network.}
Parameters are updated with Adam. The target network is updated by soft Polyak averaging after every gradient step:

\[
  \theta^- \leftarrow \tau\,\theta + (1 - \tau)\,\theta^-, \qquad \tau = 0.005.
\]

\textbf{Exploration and training schedule.}
Action selection uses $\varepsilon$-greedy exploration with linear decay from $\varepsilon = 1.0$ to $\varepsilon = 0.02$. As is standard in DQN, gradient updates are delayed until a minimum number of transitions has been collected (\texttt{learning\_starts}), after which replay-buffer samples are used for off-policy learning. In the richer experiments, the implementation can also use prioritized replay to place extra weight on informative transitions.

\textbf{Inventory masking.}
At inventory boundaries ($|I| = I_{\max}$), Q-values for actions that would deepen the position are set to $-\infty$ before the $\arg\max$, forcing the agent to quote on the unwinding side only.

\subsection{SAC Agent Architecture}

\textbf{Policy and critic.}
Experiment 4 uses Stable-Baselines3 SAC with the default multilayer-perceptron policy (\texttt{MlpPolicy}). The actor outputs a stochastic continuous policy over the four-dimensional action vector
\[
(\delta^{\mathrm{bid}}, \delta^{\mathrm{ask}}, q^{\mathrm{bid}}, q^{\mathrm{ask}}),
\]
while the critic learns soft Q-values for continuous state-action pairs.

\textbf{State and action.}
The observation is the three-dimensional continuous feature vector
\[
(I_t,\; (S_t - S_0)/10,\; \sigma_t/\bar{\sigma}),
\]
and the action bounds are
\[
\delta^{\mathrm{bid}}, \delta^{\mathrm{ask}} \in [0.1, 3.0], \qquad
q^{\mathrm{bid}}, q^{\mathrm{ask}} \in [0, 0.15].
\]

\textbf{Reward and environment.}
The reward is the same economic objective used throughout the report:
\[
r_t = \text{spread P\&L} + \text{inventory P\&L} - \alpha I_t^2,
\]
with an additional terminal inventory penalty $-\lambda |I_T|$. Fills are generated from spread-dependent Poisson intensities, price dynamics include adverse selection plus noise, and volatility follows an OU-style process.

\textbf{Training setup.}
The reported run uses a replay buffer of size $100{,}000$, learning rate $3 \times 10^{-4}$, batch size $128$, soft target update $\tau = 0.005$, discount factor $\gamma = 0.99$, automatic entropy tuning, and a total budget of $20{,}000$ environment steps. An evaluation callback tests the deterministic policy every $10{,}000$ steps and stores the best checkpoint.

\textbf{Interpretation.}
Unlike DQN, SAC does not need a discrete action grid and therefore scales naturally to the continuous quote-placement and quote-sizing problem. This is the main methodological reason it is the right final-stage algorithm for the project.
